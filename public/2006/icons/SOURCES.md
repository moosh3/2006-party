# Classic dock artwork

These are locally hosted raster assets, not generated drawings. They retain their original owners' copyright and trademarks; inclusion in an archive is not a grant of commercial reuse rights. Review permissions before wider commercial distribution.

- `safari.png`, `mail.png`, `textedit.png`: Apple application artwork from the [macOSMavericksTheme archive](https://github.com/MoonPadUSer/macOSMavericksTheme/tree/c68acc49cd4cc187bc0dad88ab5c7a5e249a730d), respectively `Safari/compass.icns`, `Mail/Mail.icns`, and `TextEdit/Edit.icns`. Converted from ICNS to transparent PNG, reduced to 128 px. These are classic pre-Yosemite versions, not claimed to be exact Tiger-release files.
- `iphone.png`: Apple first-generation iPhone device artwork, [MacIcons archive](https://github.com/TimothyRLaMora734/MacIcons/blob/23897ca7f11b9f7ae6d175a803f74c267378ee81/assets/icons/mountain-lion/com.apple.iphone.png). Reduced to 128 px. The original iPhone is a 2007 device, included at the user's explicit request. The dock button still opens the existing music player.
- `aim.png`: AOL AIM running-man logo, [PNGAAA source page](https://www.pngaaa.com/detail/8642167), original transparent download (`https://www.pngaaa.com/api-download/8642167`), reduced to 128 px. AOL branding; archive provenance does not establish a reuse license.
- Clippy uses the existing `../clippy.png` artwork, unchanged. Microsoft character; source/license was not recorded in the existing project. Its CSS frame and overflow have been removed.

Retrieved October 5, 2026. No remote image requests are needed at runtime.
